# Kubernetes

## Tổng Quan

Kubernetes là nền tảng container orchestration phục vụ triển khai toàn bộ Hanas Data Platform.

## Kiến Trúc

- **Master Nodes**: Control Plane, API Server, Scheduler
- **Worker Nodes**: Chạy workload (Pods)
- **Persistent Volumes**: Lưu trữ cho StatefulSet services
