# MinIO Site Replication

## Tổng Quan

MinIO Site Replication đồng bộ tự động dữ liệu giữa Site DC và Site DR.

## Dữ Liệu Đồng Bộ

- Data Lake (file nghiệp vụ cho Spark, Dremio)
- Thư mục backup của Velero
- Metadata hệ thống (IAM, Policies, Users)
