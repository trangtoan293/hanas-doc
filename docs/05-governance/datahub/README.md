# DataHub

## Tổng Quan

DataHub là nền tảng quản lý metadata, data catalog và data governance tập trung. Cho phép thu thập, tổ chức, quản lý và khai thác thông tin mô tả dữ liệu trong môi trường phân tán, đa nền tảng.

## Vai Trò Trong Platform

- Quản lý metadata kỹ thuật và nghiệp vụ tập trung
- Data Catalog: tìm kiếm, tra cứu, khám phá dữ liệu
- Business Glossary: từ điển thuật ngữ nghiệp vụ
- Data Lineage: truy vết luồng dữ liệu
- Data Quality tracking: theo dõi chất lượng dữ liệu
- Phân loại & tag dữ liệu
- Phân quyền quản trị (Data Owner, Steward, Custodian)

## Tính Năng Chính

1. **Centralized Metadata**: Metadata tập trung, phiên bản hóa
2. **Data Catalog**: Tìm kiếm theo tên, từ khóa, tag, domain
3. **Business Glossary**: Liên kết business term ↔ technical metadata
4. **Data Lineage**: Trực quan hóa luồng dữ liệu (table-level+)
5. **Data Quality**: Chỉ số, xu hướng, cảnh báo
6. **RBAC**: Data Owner, Data Steward, Data Custodian
