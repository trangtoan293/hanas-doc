# Lớp Xử Lý Dữ Liệu (Data Processing)

## Tổng Quan

Lớp xử lý dữ liệu chịu trách nhiệm tổ chức, điều phối, thực thi và tối ưu toàn bộ hoạt động xử lý dữ liệu từ khi thu thập đến khi sẵn sàng phục vụ phân tích và báo cáo.

| Thành phần | Vai trò |
|---|---|
| **Apache Airflow** | Điều phối & lập lịch pipeline (DAG-based orchestration) |
| **Apache Spark** | Xử lý dữ liệu phân tán trong bộ nhớ (distributed compute) |

## Services

- [Apache Airflow](apache-airflow/README.md) — Orchestration & Scheduling
- [Apache Spark](apache-spark/README.md) — Distributed Compute Engine
