# Danh sách Services

Danh mục tất cả các service trong **Hanas Data Platform**, sắp xếp theo thứ tự alphabet.

| Service | Chức năng | Vai trò trong Platform |
|---|---|---|
| [Apache Airflow](apache-airflow/README.md) | Workflow orchestration, job scheduling | Lập lịch và điều phối các pipeline dữ liệu theo DAG |
| [Apache Iceberg](apache-iceberg/README.md) | Open table format, ACID transactions | Quản lý table format cho dữ liệu trong Data Lakehouse |
| [Apache Kafka](apache-kafka/README.md) | Distributed event streaming platform | Thu thập dữ liệu real-time, CDC, event bus |
| [Apache NiFi](apache-nifi/README.md) | Data flow automation, visual ETL | Thu thập dữ liệu batch, điều phối luồng dữ liệu trực quan |
| [Apache Ranger](apache-ranger/README.md) | Authorization & access control | Quản lý phân quyền tập trung cho toàn bộ platform |
| [Apache Spark](apache-spark/README.md) | Distributed compute engine | Xử lý và tính toán dữ liệu phân tán quy mô lớn |
| [Apache Superset](apache-superset/README.md) | BI & data visualization | Trực quan hóa dữ liệu, xây dựng dashboard báo cáo |
| [DataHub](datahub/README.md) | Metadata catalog & data lineage | Quản lý metadata, catalog, và lineage dữ liệu |
| [dbt](dbt/README.md) | SQL-based ELT transformation tool | Chuyển đổi và biến đổi dữ liệu bằng SQL (Data Vault, Data Mart) |
| [Dify](dify/README.md) | AI workflow platform | Xây dựng chatbot, RAG pipeline và AI agent |
| [Dremio](dremio/README.md) | Query engine & semantic layer | Truy vấn phân tán, kết nối BI và xây dựng semantic layer |
| [HashiCorp Vault](hashicorp-vault/README.md) | Secrets management | Quản lý secret, token, certificate cho toàn bộ hệ thống |
| [Langfuse](langfuse/README.md) | LLM observability platform | Giám sát, tracing và đánh giá hiệu suất LLM |
| [MinIO](minio/README.md) | S3-compatible object storage | Lưu trữ dữ liệu thô và processed dạng object |
| [OpenObserve](openobserve/README.md) | Observability platform | Thu thập log, metrics và traces của toàn bộ platform |
| [vLLM](vllm/README.md) | LLM inference engine | Chạy mô hình LLM với API tương thích OpenAI |
