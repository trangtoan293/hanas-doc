# Lớp Điều Phối (Orchestration)

## Tổng Quan

Lớp điều phối chịu trách nhiệm lập lịch, quản lý phụ thuộc và giám sát toàn bộ pipeline dữ liệu trong hệ thống. Đây là trung tâm điều hành các luồng công việc (workflow) từ đơn giản đến phức tạp.

| Thành phần | Vai trò |
|---|---|
| **Apache Airflow** | Điều phối & lập lịch pipeline (DAG-based orchestration) |
