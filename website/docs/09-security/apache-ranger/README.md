# Apache Ranger

## Tổng Quan

Apache Ranger cung cấp framework quản lý bảo mật tập trung cho hệ sinh thái Hadoop/Data Lake, bao gồm phân quyền, audit và quản lý policy.

## Vai Trò Trong Platform

- Phân quyền truy cập chi tiết (table, column, row level)
- Quản lý policy tập trung cho nhiều services
- Audit log cho kiểm toán và tuân thủ
