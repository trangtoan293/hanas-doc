# HashiCorp Vault

## Tổng Quan

HashiCorp Vault quản lý secrets, credentials và dữ liệu nhạy cảm một cách an toàn, tập trung.

## Vai Trò Trong Platform

- Quản lý database credentials
- Quản lý API keys, tokens
- Mã hóa dữ liệu nhạy cảm
- Dynamic secrets (tạo credentials tạm thời)
